# Architecture Decision Records (ADR)

Cada ADR documenta **una decisión** relevante: su contexto, la decisión tomada, las alternativas
y las consecuencias. Son **inmutables**: si una decisión cambia, se crea un ADR nuevo que
_supersede_ al anterior (no se reescribe el viejo).

## Formato

```markdown
# NNNN — Título
- Estado: Propuesto | Aceptado | Supersedido por NNNN
- Fecha: YYYY-MM-DD
## Contexto
## Decisión
## Alternativas consideradas
## Consecuencias
```
