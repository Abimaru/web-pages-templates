# 03 · Nexo Delivery System

La forma única de entregar en ambas líneas. **No es una certificación externa.** Es la versión
comercial de la metodología **NAF** (Nexo Architecture Framework).

## Etapas

| Etapa | Rol | Qué hace |
|---|---|---|
| **Nexo Compass** | Descubrir · Mapear | Entender problema, usuarios, proceso y contexto |
| **Nexo Blueprint** | Diagnosticar · Diseñar | Diagnosticar con evidencia y diseñar con trade-offs |
| **Nexo Build** | Ejecutar | UX/UI, frontend, backend, integraciones, infraestructura |
| **Nexo Assurance** | Validar | Seguridad, calidad, accesibilidad, rendimiento, operación |
| **Nexo Transfer & Evolution** | Transferir | Documentación, handoff, capacitación, mantenimiento, evolución |

## Alineación con NAF (§7)

| NAF | Delivery System |
|---|---|
| Descubrir | Nexo Compass |
| Mapear | Nexo Compass |
| Diagnosticar | Nexo Blueprint |
| Diseñar | Nexo Blueprint |
| Ejecutar | Nexo Build |
| Validar | Nexo Assurance |
| Transferir | Nexo Transfer & Evolution |
