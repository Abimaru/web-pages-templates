# 10 · Modelo de colaboración

## Coequipo, no fábrica de entregables
Sección en NEXO LAB (`sections/Coequipo.tsx`).

> El objetivo no es entregar una caja negra. Es construir una solución que el negocio y el equipo
> puedan comprender, operar y evolucionar.

Principios: entender el contexto · construir con el cliente · hacer visibles las decisiones ·
transferir conocimiento · evitar dependencia innecesaria · dejar capacidad instalada.

## Nexo Network (oculta)
Config en `nexo-lab/src/config.ts` (`nexoNetwork`). **`enabled: false`** → **no** se muestra ningún
equipo (no se inventan colaboradores).

Capacidades futuras documentadas: UX/UI, Frontend, Backend, Cloud, Seguridad, Datos, QA, Contenido,
Marketing, Privacidad/Legal. Al habilitarla, poblar `members` con datos reales confirmados.
