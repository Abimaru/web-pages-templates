# 02 · Arquitectura de marca

```text
Estudio Abimaru
├── Soluciones web para negocios      → landing comercial + catálogo de 8 modelos (demos)
└── NEXO LAB by Abimaru               → línea de servicios profesionales de ingeniería
```

## Estudio Abimaru
Negocios, emprendimientos, comercio, presencia digital, catálogos, tiendas, aplicaciones
comerciales y automatización práctica.

## NEXO LAB
Empresas, startups, equipos técnicos, arquitectura, modernización, backend, cloud, diagnóstico,
DevOps, QA, seguridad y conocimiento para agentes.

## Capa compartida — Nexo Delivery System
Conecta ambas marcas mediante descubrimiento, evidencia, seguridad, calidad, operación y
transferencia. No es una certificación externa. Ver [03](03_NEXO_DELIVERY_SYSTEM.md).

## Reglas invariables
- NEXO LAB **no** es un modelo del catálogo y **no** incrementa el contador (sigue 8).
- NEXO LAB tiene página propia (`/nexo-lab/`) e integración no invasiva desde la landing.
- Ver ADR [`../adr/0001-marca-dos-lineas-nexo-lab.md`](../adr/0001-marca-dos-lineas-nexo-lab.md).
