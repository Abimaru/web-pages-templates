# 01 · Propuesta de valor

## Problema estratégico

Crear páginas, CRUD y prototipos con IA se volvió fácilmente replicable. La propuesta no puede
reducirse a "hacemos páginas web con IA".

## Lo que comunicamos

> Entendemos el negocio, diseñamos la solución correcta, orquestamos las tecnologías, reducimos
> riesgos y dejamos una capacidad digital que puede operarse y evolucionar.

## Principio central

```text
IA para acelerar.
Criterio profesional para decidir.
Ingeniería para responder.
```

## Cómo se demuestra (no se afirma)

- **Nexo Compass** — diagnóstico interactivo por reglas (landing).
- **Arquetipos de solución** — cada modelo explica problema, usuarios, datos, riesgos y ruta.
- **Quality Passport** — evidencia real generada en CI (build, tests, SEO…), con estados honestos.
- **Proof Room** — artefactos de ejemplo anonimizados y descargables.
- **AI-assisted, human-led** — qué acelera la IA y de qué responde el profesional.
- **Nexo Delivery Standard / Delivery System** — qué recibe el cliente además del software.

## Copy de marca

- **Estudio Abimaru:** "Diseñamos soluciones digitales para que los negocios puedan mostrar, vender,
  operar y crecer."
- **NEXO LAB:** "Orquestamos arquitectura, software, cloud, automatización y conocimiento para
  transformar procesos complejos en soluciones seguras y operables."
- **Promesa compartida:** "No entregamos solamente software. Dejamos una solución clara, validada y
  preparada para evolucionar."

Evitar: "somos los mejores", garantías absolutas, "100% seguro", "sin errores", promesas sin
evidencia. **La diferenciación se demuestra.**
