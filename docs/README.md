## Convenciones

- **ADR** = una decisión relevante por archivo, numerada e inmutable (ver [adr/README.md](adr/README.md)).
- **Iteraciones** = un reporte por tanda de trabajo, con qué se hizo, decisiones y estado.
- Los documentos viven en el repo pero **no se publican** en GitHub Pages (solo `catalogo/`
  y las apps se despliegan).
