# Política de seguridad

Este repositorio contiene **prototipos de demostración sin backend**: no procesan ni almacenan
datos reales de usuarios. Los formularios no envían nada a un servidor — solo abren WhatsApp o el
cliente de correo con un mensaje prellenado, y los diagnósticos/simuladores se calculan en el
navegador.

## Reportar un problema

Si encuentras una vulnerabilidad o un problema de seguridad o privacidad, por favor **no abras un
issue público**. Escribe a **Abimaru@gmail.com** con:

- una descripción del problema,
- pasos para reproducirlo (si aplica),
- y el proyecto/página afectada.

Se responderá y se coordinará una corrección de forma responsable.

## Buenas prácticas del repositorio

- No publiques secretos, tokens, credenciales ni datos personales en commits, issues o PRs.
- Las demos usan datos ficticios; no introduzcas datos reales de clientes.
- Las dependencias se mantienen al día; los reportes de dependencias vulnerables son bienvenidos.
